04 / FAILURE

Failure theories

Each theory works in the local material axes. The strength ratio is the factor you multiply the whole stress state by to reach failure.

Shared material & loading

The lecture offers both empirical estimates. H₁₂ requires biaxial testing for experimental determination.

Lecture benchmark

Graphite/epoxy, θ = 60°, σₓ = 2S, σᵧ = −3S, τₓᵧ = 4S. Maximum stress predicts S ≈ 16.33 MPa with shear governing.

Failure index & strength ratio

FAILURE AT INDEX ≥ 1
CRITERIONINDEXRATIO

Index < 1 means the criterion is not reached. These are linear elastic, single-ply predictions, and the theories will not always agree. Ratios only apply when the load scales proportionally.

How the criteria differ

Xₜ, X꜀, Yₜ, Y꜀ and S are positive strength magnitudes. Maximum strain chooses tensile/compressive allowable by strain sign; modified Tsai–Hill and maximum stress use stress sign. Standard Tsai–Hill uses tensile strengths, as in the lecture. Tsai–Wu can have a negative index under compressive loading; the positive strength-ratio root still defines its failure multiplier.

05 / LAMINATE

Laminate builder

Build a laminate with equal-thickness plies of one material and run Classical Lamination Theory. The first ply is the top ply, at negative z. z increases downward.

Stacking sequence

TOP → BOTTOM

Write the code as on the slides: [0/±45/90₂]s, [(0/90)₂]s, or [0/-45/\bar{60}]s for an odd middle ply. Type ± directly or as +-, and subscripts as _2. Set a ply material with 45^Gr, 45^Gl or 45^B, and a ply thickness in mm with 45:0.25. Other plies use the Material menu and the default thickness.

Temperature & moisture

Uniform ΔT and ΔC through thickness, free laminate under specified mechanical resultants. Coefficients load from Table 2.1 for a preset; shared/custom mode keeps the displayed coefficients editable.

Laminate stiffness matrices

ORDER: x, y, xy
CLT equations & modeling scope

Thin plate, perfect bonding, small deformation, plane stress in each ply. Engineering shear and twisting curvature conventions are used. Values use MPa and mm internally; N is N/mm, M is N·mm/mm (= N). Curvature is mm⁻¹. Does not predict transverse shear, edge interlaminar stresses, delamination, or progressive damage. Sequence input accepts explicit numeric angles only; use the mirror checkbox for the s suffix. Maximum 64 expanded plies.
